## 怎么使用这些笔记

先判断手头已有的材料，再看工具输出。例如：DBC 到信号值是编解码；接口卡到报文是收发；ARXML 到配置工具是模型交接；目标机器码到运行行为是仿真。几项工具常需要组合使用，并非只选其中一个。

每项起步检查都应该留下一个可以比较的结果：编解码样例、实际配置、转换前后文件、原始测量记录或失败日志。没有这些材料时，保留“文档说明”或“待评估”，不补造跑分、兼容性结论和成熟度评分。
